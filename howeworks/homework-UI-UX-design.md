# Homework: UI/UX Design — Order Owner Cart Improvement 🛒 

## Overview

Improve the cart screen for the order owner by integrating the orders of all invited guests. The objective is to present this information in a clear, structured, and easily digestible format.

## Key Requirements

* **Guest Orders Display:** Add visibility into items ordered by all guests attached to the main order.
* **UX & Functionality Enhancements:** Design additional actions and features to improve the user experience for the order owner. Potential capabilities to consider:
  * Guest order management
  * Status tracking
  * Editing and deleting items
  * Sending reminders to guests

## Primary Goal

The main goal is not just adding a new UI block, but enabling the order owner to immediately see **who ordered what** and **what actions they can perform** with those orders.
