# Homework: Business Analysis — User Story Preparation 🎯

## Task Overview

Your task is to write one or more User Stories for the feature that allows a booking organizer to view the pre-orders for the entire group.

## Requirements

### Single Screen Focus

Focus on a single screen that consolidates all pre-orders from every participant in the group.

### User Story Format

Use the standard format:

> "As a booking organizer, I want to [feature/capability] so that [benefit/value]."

### Acceptance Criteria

Include at least 3 testable Acceptance Criteria for the main User Story.

### Optional / Additional Stories

You may also write additional custom User Stories related to this feature set.
